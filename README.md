# CS4503 – Data Analytics and Visualization Lab

This repository contains the programs and sample outputs from the Chennai Institute of Technology CS4503 Data Analytics and Visualization Lab Manual.

## Experiments

1. Installation and Exploration
2. Data Handling and Analysis
   - A. NumPy arrays and operations
   - B. Pandas DataFrames
   - C. Reading data from text files, Excel, and the web
   - D. Descriptive analytics using the Iris dataset
3. Statistical Analysis Using Diabetes Datasets
   - A. Univariate analysis
   - B. Bivariate analysis: Linear and Logistic Regression
   - C. Multiple Regression analysis
   - D. Comparison of UCI and Pima datasets
4. Data Visualization and Hypothesis Testing on UCI Diabetes Dataset
   - A. Normal curves
   - B. Z-test
   - C. T-test
   - D. ANOVA
5. Model Building and Validation
   - A. Linear models
   - B. Logistic models
   - C. Time Series Analysis

## Repository conventions

Each experiment/sub-experiment is kept in its own folder with the Python program, sample output, and supporting README. Dataset files are included where practical or referenced with clear placement instructions.

The sample outputs follow the lab manual. Actual results can differ when datasets, library versions, or random/model-training conditions differ.
